as **root**, e.g. **`sudo "$(nix build --no-link --print-out-paths …#darwin-rebuild)/bin/darwin-rebuild" …`** with the same pin as the **`justfile`**; see *Known issues* in
**`docs/usage/nix-system.md`**.)

## 1. Confirm the flake is active

From the repo (with the devShell active — **`direnv allow`** in this repo or

## 2. Auth and Git signing

1. **1Password** — app unlocked; **`op signin`** if the CLI needs it.
2. **`gh auth login`** — stores credentials outside this repo (Keychain / `gh` state). Home Manager already enables `gh` and the default **git credential helper** for GitHub hosts.
3. **Commit signing (SSH)** — concinnity signs with a **dedicated personal signing key** (`concinnity signing key` in the 1Password Employee vault, registered as a signing key on juliusblank's GitHub account). It is declared in `hosts/concinnity/home.nix` as `programs.git.signing.key`. Commits under `~/github/taktile-org/`, `~/github/jbl-taktile/` and `~/work/` are overridden by the work `includeIf`: those sign with the **work key** (`github ssh key`, same 1Password vault), author as `julius.blank@taktile.com`, and verify under the work GitHub account. Local verification uses `~/.ssh/allowed_signers`, assembled from `home/common.nix` (`personalAllowedSigners`, three personal pubkeys tagged `dev@juliusblank.de`) plus `custom.extraAllowedSigners` in `hosts/concinnity/home.nix` (work pubkey tagged `julius.blank@taktile.com`).

## 3. Homebrew cleanup

Do this **after** you trust the nix-managed tools on `PATH` (see §1).

### Immediately safe (nix / HM already provide)

Examples (adjust if a formula is not installed):

```bash
brew uninstall awscli direnv tree lazygit starship gh
```

### After work devShell flakes own those workflows

When per-repo shells provide mise / pyenv / pipx / pre-commit / tfenv / mkcert / etc.:

```bash
brew uninstall mise pyenv pipx prek tfenv mkcert lsd neovim
```

Remove Brew **Python@** formulae when nothing on the system needs them.

### Orphans

```bash
brew leaves          # sanity: only what you still want from Homebrew
brew autoremove      # peel transitive formulae (see SPEC — transitive-only policy)
```

**`granted`** is in nix `home.packages` — safe to `brew uninstall granted aws-vault` if still installed via Homebrew.

## 4. AWS on the work laptop

**`~/.aws/config`** is manually managed on concinnity (generated by a work GitHub workflow). Base profiles use `credential_process = op-credential-process op://aws-vault/granted-tktliam arn:aws:iam::…:mfa/…` — this fetches IAM keys from 1Password, does `GetSessionToken` with YubiKey MFA, and caches the session in 1Password. Role profiles only need `source_profile` and `role_arn` (no `mfa_serial`). See `docs/SPEC.md` *Granted + YubiKey setup*.

**`assume <profile> [-- CMD]`** — `aws-vault exec` (8h; 2h for `*on-call-engineer-write*`), `ykman` as MFA prompt. **`login <profile>`** — console in a Firefox container. **`grassume <profile>`** — `assumego` for profiles that use `op-credential-process` (parses output, exports env vars). All tab-complete profile names.

### `~/.zshrc` (home-manager)

After **`home-manager`** has applied, **`~/.zshrc`** should be the **HM-generated** file (typically a symlink into the generation). Quick checks:

```bash
readlink ~/.zshrc
head -n 5 ~/.zshrc
```

You should see HM’s header (e.g. a “managed by Home Manager” comment). If **`~/.zshrc`** is a plain file you edited by hand, **back it up**, remove it, and run **`home-manager switch`** again so HM can install the symlink. **Remove** duplicate **`assume`** / **`complete`** blocks from any old backup so they are not sourced twice.

**`home/darwin.nix`** prunes a broken Homebrew **`_brew`** completion from **`fpath`** before **`compinit`** (avoids **`compinit:527: … _brew`**); if it still appears, run **`brew update`** / reinstall **`brew`** completions or **`brew completions link`**.
